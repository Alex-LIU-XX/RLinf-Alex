# TD3 通俗讲解：从 DDPG 到 Twin Delayed DDPG

> 这份文档是给"没读过 TD3 论文"的人写的。它从零开始讲清楚 TD3 是什么、为什么需要它、它的三个改进分别治什么病，最后回到 **RL Token（RLT）**：论文里那句"实践中跟 TD3 一致：双 Q 集成 + 取最小值算 target，ψ′ 是 target network 参数"到底用了 TD3 的哪些部分、又改了哪些部分。
>
> 相关文档：[`RL-Token_讲解.md`](./RL-Token_讲解.md)（论文精读）、[`RLinf_RLT_实现详解.md`](./RLinf_RLT_实现详解.md)（代码对照）

## 0. 一页速览

**TD3 = Twin Delayed Deep Deterministic Policy Gradient**（双延迟深度确定性策略梯度）

- 它是 **DDPG 的改良版**（2018 年，Fujimoto 等人）；
- 它解决的核心问题是：**actor-critic 类 RL 算法不稳定、估值容易虚高**；
- 它开了**三个药方**：

| 药方 | 英文 | 治什么病 |
|---|---|---|
| ① **双 Q 集成 + 取 min** | **Twin** Q-learning / Clipped Double-Q | critic 把价值**估得过高**（过估计偏差） |
| ② **延迟策略更新** | **Delayed** policy update | critic 还没学准，actor 就跟着跑，被带偏 |
| ③ **目标策略平滑** | Target policy **smoothing** | critic 在"尖峰"上过拟合，actor 被虚假高分骗走 |

（还有一个不算它发明但必须有的零件：**target network**，见第 6 节。）

**一句话**：TD3 的贡献不是"更聪明地学"，而是"**更稳健地学**"——它把 DDPG 这个"容易翻车"的算法改造成了能用的算法。

## 1. 前置词汇：10 分钟补课

如果你对 RL 的术语不熟，先看这一节；熟了可以跳到第 2 节。

### 1.1 五个基本概念

| 概念 | 符号 | 大白话 |
|---|---|---|
| **状态** | $s$ | 机器人此刻看到的东西（相机画面、关节角度…） |
| **动作** | $a$ | 机器人此刻做什么（各关节动多少） |
| **奖励** | $r$ | 此刻得分（通常是 0，只在成功时给 1） |
| **策略** | $\pi_\theta(a\mid s)$ | **该怎么做**：给定状态，输出动作。参数是 $\theta$ |
| **回报** | $G$ | 从此刻起往后**总共**能拿多少分 |

### 1.2 折扣因子 γ：为什么未来的分要打折

$$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots$$

$\gamma \in [0,1)$（典型 0.99）是**折扣因子**。

**为什么要打折？**
1. **数学上**：任务可能永远不结束，不打折总和可能是无穷大；
2. **直觉上**："现在拿到的 1 分"比"100 步后拿到的 1 分"更靠谱——越远的事情越不确定。

**打比方**：老板说"现在给你 100 块"和"一年后给你 100 块"，你肯定选前者。$\gamma$ 就是"时间折扣率"。

### 1.3 actor 和 critic：一个负责做，一个负责评

这是 actor-critic 架构的两个角色：

| 角色 | 名字 | 干什么 |
|---|---|---|
| **actor** | 策略 $\pi_\theta$ | **做决策**：看到状态，输出动作 |
| **critic** | 价值 $Q_\psi$ | **打分数**：看到"状态 + 动作"，估"这么做往后能拿多少分" |

**为什么要两个？** 因为奖励太稀疏——成功那一下才有 1 分，前面全是 0。actor 光靠"最后的结果"没法知道"中间哪一步做错了"。critic 的作用就是**把未来的分数提前预告**，给 actor 提供**每一步都能用的反馈**。

**打比方**（学开车）：
- actor = 你的手脚（负责踩油门、打方向）；
- critic = 教练（"这一把你开得不错，应该有 80 分"）。

### 1.4 Q 函数：critic 打的那个分

$$Q^\pi(s, a) = \mathbb{E}\Big[\sum_{t'=t}^{T}\gamma^{t'-t}r_{t'}\ \Big|\ s_t = s,\ a_t = a\Big]$$

读作：**"在状态 $s$ 下做动作 $a$，然后一直按策略 $\pi$ 走下去，期望能拿多少分。"**

注意两个关键：
- 它的输入是**状态 + 动作**（不只是状态）；
- 它的输出是**一个数**。

### 1.5 on-policy vs off-policy

| | on-policy | off-policy |
|---|---|---|
| 能用谁的数据 | **只能用当前策略刚产生的** | **任何**历史数据都能用 |
| 代表 | PPO | DDPG / TD3 / SAC |
| 需要经验池吗 | 通常不需要 | **必须要有**（replay buffer） |

**为什么 off-policy 重要？**
因为真机数据太贵了。off-policy 意味着：**一条数据可以反复用很多次**，而且可以把"VLA 跑的"、"旧策略跑的"、"人类接管的"数据**混在一个池子里**一起学。

**打比方**：
- on-policy = 只能用**今天刚记的**笔记复习；
- off-policy = **所有老师的笔记、自己的错题、同学教的窍门**全都能用。

### 1.6 TD 学习与"自举"（bootstrapping）—— 最关键的一个直觉

**问题**：要算 $Q(s,a)$，难道必须真的走完整局、把所有奖励加起来才知道吗？

**不用。** 有一个巧妙的关系（Bellman 方程）：

$$Q(s,a) \approx r + \gamma \cdot Q(s', a')$$

也就是说：**"这步的价值" ≈ "这一步的即时奖励" + "打折后的下一步价值"**。

这意味着：**我可以用"下一步的估值"来当"这一步估值"的老师**。不用等整局结束！

这叫 **bootstrapping（自举）**——**用自己的估计来更新自己的估计**。

**打比方**（开车导航）：你不用真的开完全程才知道这条路好不好。你开到一个路口，看导航说"这个路口以后还要 20 分钟"，加上你已经花的 10 分钟，就估出"这条路总共 30 分钟"。

**⚠️ 但自举有个危险**：老师（$Q(s',a')$）和学生（$Q(s,a)$）**是同一个网络**。如果学生每学一点，老师也跟着变，就可能变成"自己给自己打分，还不断提高标准"，最后**发散（diverge）**。

这是 DDPG 不稳定的**根本原因之一**，也是后面 **target network** 要解决的问题。

## 2. TD3 的出身：它是 DDPG 的升级版

### 2.1 名字拆解

```
Twin  Delayed  Deep  Deterministic  Policy  Gradient
 └─①─┘  └─②─┘   └─────────── DDPG ───────────┘
双Q     延迟      （它是在 DDPG 基础上改的）
```

**记住这个结构就够了**：TD3 = DDPG + 两个改动（Twin、Delayed），再 + 一个平滑技巧。

### 2.2 DDPG 本来长什么样

DDPG（2015）的核心思路：**把 DQN 的思想搬到连续动作空间**。

DQN 是"离散动作"的 Q-learning（比如游戏里 4 个按键选一个），但机器人动作是**连续的**（关节转多少度，可以是 0.37 这种任意数），没法"把所有动作枚举一遍取 max"。

DDPG 的解法：**用一个 actor 网络直接输出那个"最好的动作"**，替掉 DQN 里的 `max` 操作。

DDPG 的四个零件：

| 零件 | 作用 |
|---|---|
| **actor $\pi_\theta(s)$** | **确定性**策略：给定状态，直接输出一个动作（不是分布！） |
| **critic $Q_\psi(s,a)$** | 打分器 |
| **replay buffer $\mathcal{B}$** | 经验池，存历史 transition |
| **target networks $\theta', \psi'$** | 慢半拍的旧副本，用来算 TD target（治 1.6 节说的自举发散问题） |

再加上一个工程技巧：**探索噪声**。actor 是确定性的，不随机就没法探索，所以执行时给它加个高斯噪声 $a = \pi_\theta(s) + \epsilon$。

### 2.3 DDPG 的毛病

DDPG 在论文里能跑，但**换个环境就经常崩**。TD3 论文系统分析了几个原因：

| # | 毛病 | 后果 |
|---|---|---|
| 1 | **Q 值被系统性高估**（过估计偏差） | actor 追着虚假高分跑 → 策略退化 |
| 2 | **actor 更新太勤** | critic 还没学准，actor 就跟着错的信号跑 → 震荡 |
| 3 | **critic 在窄峰上过拟合** | actor 被"尖峰"吸引 → 学到脆弱的策略 |

下面三节分别讲 TD3 的三副药。

## 3. 药方一：Twin Q —— 双 Q 集成 + 取最小值

### 3.1 什么是"过估计偏差"

**过估计（overestimation）** = critic 给出的分数，系统性地**高于真实值**。

**为什么会发生？**

第一层原因：**函数逼近误差**。critic 是个神经网络，永远有误差。这个误差可正可负。

第二层原因（更本质）：**取 max 会把噪声"筛选"成正偏差**。

**用一个具体数字例子讲清楚**（这个例子很重要）：

> **先把"无偏"这个词讲清楚**（很容易被误读）
>
> **无偏（unbiased）= 估计值的"期望"等于真值**，即 $\mathbb{E}[\hat Q] = Q^*$。
>
> "期望"就是**长期平均**。所以无偏的意思是：**如果换随机种子、把这个 critic 从头重训 1000 次，把这 1000 个结果平均起来，会得到真值。**
>
> 注意：**它完全不保证"手上这一次训练的结果"等于真值。** 单次可以偏很多、可正可负——那部分就是"噪声"。随机性来自参数随机初始化、mini-batch 随机采样、探索噪声、数据顺序……每次重训都不同。
>
> **偏差（bias）和方差（variance）是两件事**，用打靶打比方：
>
> | | 含义 | 打靶的样子 |
> |---|---|---|
> | **无偏 + 有噪声** | 弹着点的**中心**在靶心，但散得很开 | 围着靶心一团散点 |
> | **有偏 + 低噪声** | 打得很集中，但整体偏左 | 靶心左边一小撮 |
>
> 下面例子里这两个 critic 属于**第一种**：每一次都打偏，但**平均下来**在靶心上。

假设某个状态-动作对的**真实价值**是 $Q^* = 0$。
我们训了两个 critic，它们的估计都**无偏**但**有噪声**：

$$Q_1 = +0.5, \qquad Q_2 = -0.3$$

- 取 **max**：得到 $+0.5$ → **高估了 0.5**
- 取 **min**：得到 $-0.3$ → **低估了 0.3**
- 取 **mean**：得到 $+0.1$ → 接近 0，比较准

**注意**：$Q_1$ 和 $Q_2$ 的**平均值确实是 0**（无偏），但**取 max 之后就不是 0 了**。

这在数学上有一般性结论：

$$\mathbb{E}\big[\max(Q_1, Q_2)\big] \;\ge\; \max\big(\mathbb{E}[Q_1], \mathbb{E}[Q_2]\big)$$

即使 $Q_1, Q_2$ 各自无偏，**取 max 也会引入正偏差**。

**打比方**：两个人各自猜一个数，都可能有高有低。如果你**每次只采信猜得高的那个人**，那长期下来你的估计必然偏高。

#### 数值验证：偏差纯粹来自 `max` 这个操作

把上面的假设跑一遍（真实值 $Q^* = 0$，两个估计 $Q_1, Q_2 \sim \mathcal{N}(0, \sigma^2)$，各采样 20 万次）：

| 噪声 $\sigma$ | $\mathbb{E}[Q_1]$ | $\mathbb{E}[\max]$ | $\mathbb{E}[\min]$ | $\mathbb{E}[\text{mean}]$ |
|---|---|---|---|---|
| 1.0 | 0.003 | **0.569** | −0.562 | 0.003 |
| 0.5 | −0.001 | **0.282** | −0.282 | −0.000 |
| 0.1 | −0.000 | **0.056** | −0.056 | −0.000 |
| 0.01 | −0.000 | **0.006** | −0.006 | −0.000 |

可以读出三件事：

1. **单看任何一个 critic 都是无偏的**（第 2 列 ≈ 0）；
2. **`max` 引入了正偏差**，而且恰好是 $\sigma/\sqrt{\pi}$（对两个独立标准正态，$\mathbb{E}[\max] = 1/\sqrt{\pi} \approx 0.5642$，是解析解）；
3. **偏差大小与噪声成正比**：估计越不准，`max` 的偏差越大。这也意味着——**在训练早期、critic 还很差的时候，过估计最严重**。

**结论**：这个偏差**不是来自哪个 critic 本身**，而是来自 `max` 这个非线性操作（以及 RL 里的取值操作）。$\mathbb{E}[\max] \neq \max(\mathbb{E})$。

> ⚠️ **一个诚实的补充**：上面是**理想化模型**（假设估计无偏、只挑出 `max` 这一条机制看）。真实的神经网络 Q **并不严格无偏**，过估计有多重来源：
> - `max`/取极值操作（上表这一条）；
> - **函数逼近误差**：网络表达能力有限，会在某些区域系统性高估；
> - **自举自激**：被高估的值又被当作 target（见下一小节）；
> - **分布外动作被高估**（对 actor-critic 尤其重要）：actor 会主动往"critic 没见过、却恰好估得高"的地方跑，而 critic 在没数据的地方只能靠外推，往往瞎猜。
>
> 所以 TD3 的双 Q 与其说"消除偏差"，不如说**主动引入一个反向（悲观）偏差去对抗向上的偏差**——这是一笔"用保守换稳定"的交易。

### 3.2 为什么这个偏差会"滚雪球"

单独一次高估不要紧，**要命的是它会自我强化**：

```
Q(s,a) 被高估
   ↓
用这个被高估的 Q 当 target，去训练 Q(s,a)
   ↓
新学到的 Q 又更高一点
   ↓
...循环...
   ↓
估计值一路飙到不合理的水平，actor 开始追这个虚假目标
```

**打比方**：一个人吹牛说自己月入十万，别人信了，他为了圆谎只好说更多，最后数字越滚越大。**bootstrapping 会把偏差一遍遍放大。**

### 3.3 TD3 的解法：养两个 critic，取小的那个

**做法**：训练**两个完全独立的 Q 网络** $Q_{\psi_1}$ 和 $Q_{\psi_2}$（结构相同、参数不同、初始化不同），然后**在算 target 时取两者的最小值**：

$$y = r + \gamma \min_{i=1,2} Q_{\psi'_i}(s', a')$$

其中 $\psi'_i$ 是两个对应的 target network。

**为什么取 min 有效？**
因为过估计是"向上偏"，取 min 就引入了一个**主动的悲观偏置**去抵消它。

回到刚才的例子：真实值 0，两个估计 $+0.5$ / $-0.3$，取 min 得 $-0.3$。虽然这次低估了，但**长期平均下来，取 min 的偏差方向恰好和过估计相反**，两者互相拉扯，最终落点更接近真值。

**打比方**：找两个朋友帮你估价一辆二手车。一个天生乐观（总报高），一个天生保守（总报低）。**你只信保守那位**——因为在这种场景下，"高估"的代价（花冤枉钱）比"低估"（错过好车）更糟。

**⚠️ 一个容易搞混的点**：取 min **只用在计算 target 的时候**。损失函数里两个 Q 头**都去拟合这同一个 target**：

$$\mathcal{L} = \big(y - Q_{\psi_1}(s,a)\big)^2 + \big(y - Q_{\psi_2}(s,a)\big)^2$$

**为什么不干脆只留一个 Q？** 因为如果只留一个，那个就没有"参照物"了。两个网络**独立初始化 + 独立训练**，它们的误差才**不完全相关**；正是这种"两个不同视角"，取 min 才有意义。

**⚠️ 另一个常见疑问**：既然要两个独立网络，为什么还要**两个共享？** 不是共享——TD3 用的是**两个完全独立的网络**（只共享输入）。有些实现为了省算力会共享前面的特征层，但原始 TD3 是独立的。RLinf 里 `TwinQCritic` 就是两个独立的 `QNetwork`。

### 3.4 一个小结

| | DDPG | TD3 |
|---|---|---|
| critic 个数 | 1 | 2 |
| target 用的 Q | $Q_{\psi'}$ | $\min(Q_{\psi'_1}, Q_{\psi'_2})$ |
| 效果 | 偏向高估 | 偏向保守，更接近真值 |

## 4. 药方二：Delayed —— 延迟策略更新

### 4.1 问题在哪

actor 的训练目标是"**往 critic 认为价值高的方向走**"：

$$\nabla_\theta J \approx \mathbb{E}\big[\nabla_a Q_\psi(s,a)\big|_{a=\pi_\theta(s)} \cdot \nabla_\theta \pi_\theta(s)\big]$$

注意：**actor 的梯度依赖 critic 的判断**。

于是问题来了：

- **critic 刚开始时基本是个随机函数**，它的"价值高地"全是噪声；
- 如果 actor 更新得和 critic 一样勤，它就会**追着噪声跑**；
- 等 critic 学准了，actor 已经跑偏很远，还要花时间回来。

**打比方**：一个新手教练给运动员瞎指挥，运动员如果**每句话都照做**，就会来回乱跑。理智的做法是——**教练先多看几场比赛，想清楚了再给运动员发指令。**

### 4.2 TD3 的解法：让 critic 多更新几次，再更新 actor

TD3 的做法很朴素：**actor 的更新频率是 critic 的一半**。

标准实现是：

```
每 1 次 critic 更新 → 更新 critic
每 2 次 critic 更新 → 顺便更新一次 actor
```

论文原话（TD3 原始论文）：*"We update the policy network every d iterations... we used d = 2."*

**效果**：
- critic 有更多时间把价值函数学准；
- actor 收到的是**更可信的梯度**；
- 训练整体的震荡明显减小。

**这也解释了为什么"延迟"（Delayed）会被写进名字里**——它是 TD3 三个改进中最容易被忽略、但实际很重要的一条。

> 📌 **记住 2:1 这个比例**。后面讲 RLT 时会看到：论文里明确说"每 1 次 actor 更新配 2 次 critic 更新"，正是从 TD3 这里来的。

## 5. 药方三：Target Policy Smoothing —— 目标策略平滑

### 5.1 问题在哪：critic 的"尖峰"陷阱

#### 什么是"尖峰"

**尖峰（spike）= 价值函数 $Q(a)$ 曲面上的一小块区域：它又窄又高，但那里的真实价值其实很低。**

三个特征缺一不可：

| 特征 | 含义 |
|---|---|
| **窄** | 只在很小的一段动作区间里高，稍微偏一点就掉下去 |
| **高** | 比周围高出一大截（常常比邻居高出好几倍） |
| **假** | 它是**估计误差的产物**（artifact），不是真的"好动作" |

它和"一个正常的价值高点"的区别在于：正常的高点对应**真实的好动作**（比如"对准孔口的时候"）；尖峰只是**神经网络在没数据的地方脑补出来的一个包**。

#### 尖峰是怎么"长"出来的：三步机制

**第 1 步：数据点极其稀疏。**
确定性策略（DDPG/TD3 的 actor）每一步只在**一个**动作 $\pi_\theta(s)$ 上查询 critic。所以 critic 的训练数据是一堆**孤立的点**，点与点之间是**大片空白**。

**第 2 步：这些"点"的高度本身带噪声。**
critic 的 target 是 $r + \gamma\min(Q'_1, Q'_2)$，里面混了自举、取 min、随机采样，本身就有噪声。所以这些点的高度是抖动的，有的点被偶然估高。

**第 3 步：网络必须"脑补"点与点之间的值，而且没有任何东西约束它。**
损失函数**只在数据点上定义**。点与点之间怎么连，网络爱怎么连就怎么连。于是——**为了穿过一个偏高的噪声点，它会在中间拱起一个包**。那个包就是尖峰。

#### 实测：尖峰长什么样

**设置**：真实曲线 $Q(a) = \dfrac{1}{1+25a^2}$（平滑单峰，真峰在 $a=0$，最大 1.0）；critic 只在 15 个动作点上见过数据，target 加 $\sigma=0.05$ 的噪声。

**结果一：单次训练就能长出明显的假尖峰**

| $a$ | 真实 $Q$ | critic 估计 | |
|---|---|---|---|
| **−0.80** | 0.0588 | **0.2712** | ← 高了 **4.6 倍**，假尖峰 |
| −0.60 | 0.1000 | 0.0180 | |
| −0.20 | 0.5000 | 0.4948 | 数据点附近，估得挺准 |
| 0.00 | 1.0000 | 1.0154 | 真峰 |
| +0.80 | 0.0588 | 0.1802 | ← 又一个假尖峰，高 3 倍 |

**结果二：统计 300 次不同噪声**

| 指标 | 数值 |
|---|---|

| 最高点被高估 > 0.02 的比例 | 27.7% |

| **critic 认为的最高点位置的标准差** | **±0.4211** |

最后那一行最震撼：**真峰始终钉在 $a=0$ 一动不动，但 critic 心里的"最高点"却能在 ±0.42 的范围里到处乱跑。**

#### 为什么它是陷阱：actor 是"主动去追"的

关键洞察：**actor 不是被动受害，它是在主动寻找 critic 的错误。**

actor 的更新规则就是**梯度上升**：

$$\theta \leftarrow \theta + \alpha\,\nabla_\theta \pi_\theta(s)\cdot \nabla_a Q(s,a)\big|_{a=\pi_\theta(s)}$$

它在做的事就是"**往 Q 高处爬**"。所以：

- critic 的**每一个错误高点，都是 actor 的追逐目标**；
- actor 会**专挑 critic 学得最差的区域钻**。

**这是一种"对抗"关系**，和另外两件事是**同一类现象**：

- **GAN**：生成器专门找判别器的漏洞；
- **RLHF**：策略专门找奖励模型的漏洞（reward hacking，比如"写得很长但没内容"骗高分）。

**打比方**：你在山谷里找最高点，手里只有一张**有测绘误差的地图**。地图上有个孤立的假高峰，你按地图爬过去，到了才发现是假的——但你已经把营地建在那儿了。更糟的是，**地图不会自己改**，你下次还会去。

#### 为什么"窄"才是真正致命的

| 尖峰的形态 | 后果 |
|---|---|
| **宽的高原**（一大片区域都偏高） | 站上去行为不会太离谱，只是"保守 / 次优" |
| **窄的尖峰**（只在一小段里高） | 最优行为只在那 ~1% 的动作空间里有效，稍微偏一点就掉崖 → **策略极度脆弱** |

**窄峰是过拟合的典型特征**：只在训练数据精确经过的那一点上对，换个状态、加一点噪声就崩。这就是前面说的"策略变得脆弱"的原因。

#### 为什么确定性 actor 特别容易中招

| | 确定性 actor（DDPG / TD3） | 随机 actor（SAC） |
|---|---|---|
| 每步问 critic 几次 | **1 个点** | 从分布采样，隐性覆盖**一小片区域** |
| critic 的训练密度 | 极稀疏，点间大片空白 | 相对稠密 |
| 尖峰的生长空间 | **大** | 小（采样本身就有平滑作用） |

这就是为什么 **SAC 不太需要 target policy smoothing，而 TD3 必须加**——TD3 的确定性策略把 critic "饿"得太狠了，得人为喂它一点邻域信息（下一小节）。

### 5.2 TD3 的解法：给 target 动作加噪声

**做法**：在算 target 的时候，不要用"下一状态那个精确的动作 $a'$"，而是用一个**加了一点噪声的动作**：

$$a' = \mathrm{clip}\Big(\pi_{\theta'}(s') + \mathrm{clip}(\epsilon,\ -c,\ c),\ a_{\min},\ a_{\max}\Big), \qquad \epsilon \sim \mathcal{N}(0, \sigma^2)$$

拆开看：

| 步骤 | 作用 |
|---|---|
| $\pi_{\theta'}(s')$ | target actor 给出的动作 |
| $+\ \epsilon$ | 加一个高斯噪声（原始论文 $\sigma = 0.2$） |
| $\mathrm{clip}(\epsilon, -c, c)$ | **先裁噪声**，防止加太离谱（原始论文 $c = 0.5$） |
| $\mathrm{clip}(\cdot, a_{\min}, a_{\max})$ | **再裁动作**，保证在合法动作范围内 |

### 5.3 为什么叫"平滑"

因为这样一来，critic 就**不允许**只在一个点上给高分了——它必须在**那个点周围的一小圈**上都给出相近的分数，否则这圈的样本会拉着它改。

**效果**：价值曲面被"抹平"，尖峰被削掉，actor 也就不会被虚假高峰骗走。

**打比方**：不再只在一个点上取样打分，而是在**周围撒一把沙子一起打分**，逼打分器给出平滑的分数曲面。

**⚠️ 注意一个方向性**：噪声是加在 **target** 里的（算 $y$ 时），**不是**加在 actor 实际执行的动作上。也就是说，**它改变的是"critic 学什么"，不是"机器人做什么"**。

### 5.4 探索噪声 vs 平滑噪声：别搞混

TD3 里其实有**两种噪声**，作用完全不同：

| | 探索噪声 | 平滑噪声 |
|---|---|---|
| 加在哪 | **执行时**：$a = \pi_\theta(s) + \epsilon$ | **算 target 时**：$a' = \pi_{\theta'}(s') + \epsilon$ |
| 给谁用 | 环境 | critic 的训练目标 |
| 目的 | **探索**新动作 | **平滑** Q 函数 |
| 典型值 | $\sigma = 0.1$ | $\sigma = 0.2$，clip $c = 0.5$ |
| 影响谁 | 机器人实际行为 | 只是训练信号 |

**这个区分非常重要**，因为很多实现（包括 RLinf 的 TD3 变体）会**复用同一个噪声参数**，读代码时会看晕。

## 6. 别忘了一个基础零件：Target Network

这个不是 TD3 发明的（DQN/DDPG 就有），但**必须理解它**，否则前面三副药都看不懂。

### 6.1 问题：老师不能是自己

回到 1.6 节说的自举危险。我们要用 $Q(s',a')$ 当 target，但 **$Q$ 自己正在被训练**。

如果直接用当前网络算 target：

```
用 Q 算 target  →  用 target 训练 Q  →  Q 变了  →  target 也变了
   ↑                                                      │
   └──────────────────────────────────────────────────────┘
        （老师和学生一起动，互相追，容易发散）
```

**打比方**：考试不能自己批自己的卷子。你写了答案，自己批"全对"，然后按"全对"的标准继续学——听起来荒谬，但这就是"用同一个网络算 target"在做的事。

### 6.2 解法：养一个"慢半拍"的旧副本

单独维护一套参数 $\psi'$（target network），**专门用来算 target**。它平时不参与训练，只是**慢慢地**从主网络同步过去。

这就是论文里那句 *"$\psi'$ 是 target network 参数"* 的含义。

### 6.3 同步方式一：硬更新（hard update）

每隔 $N$ 步，直接把主网络的参数**整个复制**给 target：

$$\psi' \leftarrow \psi \quad (\text{every } N \text{ steps})$$

- 优点：简单；
- 缺点：每次同步的瞬间，target 会**跳变**，训练曲线容易出现台阶。

### 6.4 同步方式二：Polyak 软更新（TD3 用的）

**每步都更新，但每次只挪一点点**：

$$\psi' \leftarrow \tau\psi + (1-\tau)\psi'$$

其中 $\tau$ 是一个很小的数（典型 $0.005$）。

展开看：新 target = $0.995 \times$ 旧 target + $0.005 \times$ 当前主网络。也就是**每步只往主网络挪 0.5%**。

**效果**：target 像"影子"一样平滑地跟着主网络漂移，**没有跳变**。这也让训练曲线更平滑。

**打比方**：
- 硬更新 = 每隔一小时换一次司机（接手瞬间会抖一下）；
- 软更新 = 让新司机**一点一点**把手放到方向盘上，**无缝交接**。

### 6.5 小表

| | 硬更新 | Polyak 软更新 |
|---|---|---|
| 频率 | 每 N 步 | **每步** |
| 幅度 | 100% | $\tau$（如 0.5%） |
| 曲线 | 有台阶 | 平滑 |
| 用在哪 | DQN | DDPG / TD3 / SAC |

## 7. TD3 完整算法（逐步讲解）

把前面的零件拼起来：

```text
初始化：
  actor  π_θ            （确定性策略）
  critic Q_ψ1, Q_ψ2     （两个独立网络）
  target  θ' ← θ,  ψ'1 ← ψ1,  ψ'2 ← ψ2
  replay buffer B ← ∅

重复直到收敛：

  ── 采集阶段 ──────────────────────────────
  1. 选动作：a = clip(π_θ(s) + ε, a_min, a_max),  ε ~ N(0, σ_explore)
     ↑ 加探索噪声，否则确定性策略永远只走同一条路
  2. 执行 a，观察 r, s'
  3. 把 (s, a, r, s') 存进 B

  ── 更新阶段（每个 batch 做一次）──────────
  4. 从 B 随机抽一批 (s, a, r, s')

  5. 算 target：
     a' = clip(π_θ'(s') + clip(ε, -c, c), a_min, a_max)     ← 药方三：平滑
          其中 ε ~ N(0, σ_smooth)
     y  = r + γ · min(Q_ψ'1(s', a'), Q_ψ'2(s', a'))          ← 药方一：Twin

  6. 更新两个 critic：
     L = (y - Q_ψ1(s,a))² + (y - Q_ψ2(s,a))²
     梯度下降

  7. 【每 2 次循环才做】更新 actor：                        ← 药方二：Delayed
     ∇_θ J = -∇_θ Q_ψ1(s, π_θ(s))        （注：通常只用 Q1，不用 min）
     梯度上升（最大化 Q）

  8. 软更新 target：
     ψ'1 ← τψ1 + (1-τ)ψ'1
     ψ'2 ← τψ2 + (1-τ)ψ'2
     θ'  ← τθ  + (1-τ)θ'
```

**注 7 里那个细节值得一说**：更新 actor 时通常**只用 $Q_{\psi_1}$**（第一个 critic），而不是用 $\min$。因为 $\min$ 主要是为了给 target 降偏，如果 actor 也追 min，可能会**过于保守**、学不动。这是个常见的实现约定。

## 9. 回到 RL Token：哪部分用了 TD3，哪部分改了

### 9.1 论文那句话到底在说什么

> "实践中跟 **TD3** 一致：双 Q 集成 + 取最小值算 target，$\psi'$ 是 target network 参数。"

翻译成大白话：**RLT 的 critic 用了 TD3 那套"防高估 + 稳住 target"的机制**，具体是：

| TD3 的零件 | RLT 用了吗 | 说明 |
|---|---|---|
| **双 Q 集成** | ✅ | 两个 Q 头 |
| **target 取 min** | ✅ | $\min(Q_{\psi'_1}, Q_{\psi'_2})$ |
| **target network** | ✅ | $\psi'$，Polyak 软更新 |
| **延迟策略更新** | ✅ | 论文："每 1 次 actor 更新配 2 次 critic 更新" |
| **目标策略平滑** | ⚠️ | 论文正文没强调；代码里的 TD3 变体是用"给 target 动作加同一个噪声 + clamp"来近似 |
| **确定性 actor + 探索噪声** | ⚠️ | 只有 TD3 **变体**是这样；**AC 主线**用的是高斯策略 |

**关键点**：论文说"跟 TD3 一致"，主要指的是 **critic 的稳定机制**（双 Q + target net + 延迟），**不是说整个算法就是 TD3**。

### 9.2 RLT 相对 TD3 改了哪些（重要）

RLT 和标准 TD3 有**四个本质区别**：

#### 区别一：动作是"块"，不是"单步"

- TD3：actor 输出**一个**动作（比如 1×14 维）；
- RLT：actor 输出**一整个动作块**（比如 10×14 = 140 维）。

critic 也相应地对整块估值：$Q(x, a_{1:C})$。

**这不是小事**——它让 TD 备份一次跨越 C 步，把稀疏奖励的传播距离缩短了 C 倍。**这是 RLT 能学会的根本原因之一**，TD3 里没有这个。

#### 区别二：AC 主线不是"确定性 actor"，而是高斯策略

- TD3：$\pi_\theta(s)$ 输出**一个确定的动作**，靠外部加噪声来探索；
- RLT 的 **AC 主线**：$\pi_\theta(a \mid x, \tilde a) = \mathcal{N}(\mu, \sigma^2 I)$，输出**一个分布**，采样得到动作。

RLT 里 $\sigma$ 是**固定的小常数**（`fixed_std: 0.002`），而且**没有熵项**。所以它既不是标准 TD3，也不是标准 SAC，而是一个"**固定噪声的高斯 actor + 双 Q critic + BC 正则**"的混合体。

> 📌 在 RLinf 代码里，AC 主线的 worker 类名叫 `RLTACFSDPPolicy`，它**继承自** `EmbodiedSACFSDPPolicy`（SAC 的基类），但把熵项关掉了（`forward_alpha` 直接抛 `NotImplementedError`，`alpha = 0`）。所以代码注释里也写了一句：*"The current Stage 2 implementation is not standard maximum-entropy SAC."*

#### 区别三：actor 条件在 VLA 参考动作上（TD3 完全没有）

$$\pi_\theta(a_{1:C} \mid x, \tilde a_{1:C})$$

这个 $\tilde a$（VLA 的参考动作）是 RLT 独有的，TD3 里不存在。

#### 区别四：多了一项 BC 正则

$$\mathcal{L}_\pi = \underbrace{-Q_\psi(x,a)}_{\text{TD3 有}} + \underbrace{\beta\|a - \tilde a\|_2^2}_{\text{RLT 新增}}$$

TD3 是"无约束地追 Q"，RLT 是"在参考动作附近追 Q"。

### 9.3 RLinf 里的具体数值对照

| 超参 | 标准 TD3 | RLinf 的 AC 主线 | RLinf 的 TD3 变体 |
|---|---|---|---|
| critic 个数 | 2 | 2（`MultiQHead(num_q_heads=2)`） | 2（`TwinQCritic`） |
| target 取 min | ✅ | ✅ `_min_twin_q` | ✅ `_min_twin_q` |
| actor 用的 Q | 通常 $Q_1$ | **$Q_1$**（`actor_agg_q: q1`） | $\min$（`actor_agg_q: min`） |
| 延迟更新比例 | 2:1 | **4:1**（`critic_actor_ratio: 4`） | **2:1**（`critic_actor_ratio: 2`）✅ |
| $\gamma$ | 0.99 | 0.99 | 0.99 |
| $\tau$ | 0.005 | 0.005 | 0.005 |
| target 更新频率 | 每步 | 每步（`target_update_freq: 1`） | 每步 |
| actor 输出 | 确定性 + 噪声 | **高斯**，`fixed_std=0.002` | 确定性 + 噪声 $\sigma=0.1$ |
| a′ 从哪来 | **target actor** | ⚠️ **在线 actor**（`self.model`） | **target actor** ✅ |
| 平滑噪声 | $\sigma=0.2$, clip $c=0.5$ | ❌ 无 | 复用 $\sigma=0.1$ + `clamp(-1,1)` |
| BC 正则 | ❌ | ✅ | ✅ |

**⚠️ 三处值得注意的差异**（在 [`RLinf_RLT_实现详解.md`](./RLinf_RLT_实现详解.md) 里也标了）：

1. **AC 主线的 a′ 用的是在线 actor，不是 target actor**。严格 TD3 应该用 target actor + 平滑噪声。只有 **TD3 变体**才做对了这一点。
2. **延迟更新比例**：AC 主线是 **4:1**，只有 TD3 变体是 TD3 标准的 **2:1**（也就是论文说的 2:1）。
3. **平滑噪声**：RLinf 的 TD3 变体没有单独的 `policy_noise` / `noise_clip` 参数，而是**复用 actor 的探索噪声 $\sigma=0.1$**，用 `clamp(-1,1)` 当裁剪。这是简化，不是标准 TD3 的 $\sigma=0.2$ / $c=0.5$。

## 10. TD3 vs SAC：顺便分清（因为 RLT 两个都沾）

你可能会疑惑：RLInf 的 AC 主线继承的是 **SAC** 的基类，但论文说跟 **TD3** 一致。这两个算法到底什么关系？

| | TD3 | SAC |
|---|---|---|
| actor 类型 | **确定性** | **随机**（高斯） |
| 探索方式 | 外部加噪声 | 从策略分布采样 |
| 熵正则 | ❌ | ✅ **最大熵**（鼓励多样性） |
| 温度 α | ❌ | ✅ 通常自动调节 |
| target 取 min | ✅ 双 Q | ✅ 双 Q |
| target network | ✅ | ✅ |
| 延迟更新 | ✅ | ❌（每步都更新） |

**简单记**：**SAC = 随机策略 + 最大熵 + 双 Q**；**TD3 = 确定性策略 + 探索噪声 + 双 Q + 延迟 + 平滑**。

**它们共享的**是"双 Q 防高估 + target network"这套稳定机制——**这也正是 RLT 从它们那里借来的部分**。

而 RLT 的 AC 主线，是**站在 SAC 的代码框架上、但把熵项关掉（α=0）、把方差固定**，同时借了 TD3 的双 Q + 延迟——所以它是一个**混合体**。这也解释了为什么代码里会有一句"不是标准 SAC"的注释。

## 11. 常见疑问

**Q：尖峰是不是只在"没数据的地方"出现？**
A：主要在那里。有数据的地方，损失函数会把估计拉住；**没数据的地方才是网络的"自由发挥区"**。而确定性策略恰恰制造了大量空白区——这就是 5.1 节三步机制的第 1 步。

**Q：那多采点数据不就行了？**
A：方向对，但真机数据太贵。"让 critic 在动作空间里覆盖得更密"正是 target policy smoothing 用**几乎免费的方式**（只加个噪声）达到的效果。

**Q：尖峰会不会其实是"真的有更好的动作但还没被发现"？**
A：区分方法是**去验证**——真的到那个动作上执行一下。绝大多数情况是假的（噪声 + 外推的产物）。如果真是好的动作，它应该在**一片邻域**上都好，而不是只在一个点上高。这正是平滑噪声要检验的东西。

**Q：为什么 Q 曲面上有"局部极大值"会是麻烦？RL 不就是要找最大值吗？**
A：找最大值没错，问题是**梯度上升只能爬"最近的"那个峰**（局部最优）。如果附近有个假峰，actor 就先奔它去了。所以"探索"和"平滑"决定了你会掉进哪个盆地。

**Q：为什么 TD3 的 actor 是确定性的？确定性不会失去探索能力吗？**
A：会，所以 TD3 **在执行时加高斯噪声**（探索噪声）。确定性 actor 的优点是：训练时目标明确（直接找 Q 的梯度方向），不需要在分布上做重参数化，实现更简单、也更稳。探索的责任被分离出去了。

**Q：双 Q 的两个网络为什么要独立初始化？共享不是更省显存吗？**
A：因为取 min 只有在**两个误差不完全相关**时才有意义。如果共享大部分参数，两个 Q 会给出几乎一样的估计，取 min ≈ 取任意一个，白搭。

**Q：取 min 是"双 Q 里更悲观的那个"，那会不会一直低估，导致学不动？**
A：理论上会引入低估偏置。但在实践中，**过估计的问题远比低估严重**（过估计会导致策略追着虚假目标跑，直接崩），而低估最多是"保守一点"。所以这笔交易划算。而且 actor 更新时通常只用 $Q_1$（不取 min），进一步减小了过度保守的风险。

**Q：$\tau = 0.005$ 会不会太慢？target 要 200 步才能跟上 ~63%？**
A：就是要它慢。target network 的作用是"提供稳定的锚"，不是"紧跟主网络"。$0.005$ 意味着 target 的时间常数约 $1/\tau = 200$ 步，这个滞后正是稳定性的来源。太大会退化成一个普通网络（回到 6.1 节的发散问题）。

**Q：延迟更新的"延迟"和 target network 的"慢"是一回事吗？**
A：不是。**target network 慢**是"我的 target 更新得慢"；**延迟更新**是"我的 actor 更新得少"。一个管"打分标准稳不稳"，一个管"多久听一次打分"。

**Q：为什么 target policy smoothing 的噪声要 clip？**
A：防止噪声把 target 动作推到**完全无关的区域**。比如目标动作是"往左 0.1"，噪声一下加了 5，变成"往左 5"——那这个 target 就毫无意义了。clip 把它限制在一个合理的小邻域内。

**Q：这一整套和 RLT 里"双 Q 取 min"那句话什么关系？**
A：那句话是 RLT 在说："**我 critic 的稳定机制直接借用 TD3 的，不重新发明**。"所以它特别提了双 Q 集成、取 min、target network 这三样。至于 TD3 的"确定性 actor"和"平滑噪声"，RLT 并没有完全照搬。

## 12. 一页总结

```
DDPG：确定性 actor + 1 个 Q + target net + 经验池
         └── 毛病：Q 高估、actor 更新太勤、critic 过拟合尖峰

TD3 = DDPG 的三副药：
   ① Twin      两个 Q，target 取 min    → 治过估计
   ② Delayed   每 2 次 critic 才更新 1 次 actor  → 治"跟着噪声跑"
   ③ Smoothing target 动作加裁剪噪声     → 治"追虚假尖峰"
   （外加 target network 的 Polyak 软更新提供稳定锚）

RLT 借用的是：双 Q + 取 min + target network + 延迟更新
RLT 改掉的是：动作变成"块"、actor 变成条件化高斯策略、加 BC 正则
```

**记这一句就够**：**TD3 的核心贡献是"让 Q 别虚高、让 actor 别瞎跑"——RLT 正是靠借用这套稳健机制，才能在几十分钟的真机练习里不崩。**
